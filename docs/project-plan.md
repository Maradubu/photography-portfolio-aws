Project Plan
Objective

Build a personal photography portfolio that can eventually be expanded into an online shop.

The project will be used to develop practical skills in AWS, Linux, Python programming, networking, security and version control.

Initial Scope

The first version will focus on establishing the development workflow and creating a simple photography gallery.

E-commerce features, customer accounts and payment processing are outside the initial scope.

Learning Principles
Understand the purpose of each tool and service.
Build practical skills through small, connected exercises.
Test results and investigate errors.
Document important technical decisions and troubleshooting steps.
Introduce new technologies when the underlying concepts are understood.

Planned Milestones
Set up the local development environment and Git workflow.
Practise file management and command-line fundamentals.
Apply Python programming concepts to useful project scripts.
Develop a basic photography gallery.
Learn and apply AWS hosting, networking and security concepts.
Deploy and troubleshoot the website.
Explore automation and more advanced cloud technologies when ready.
Current Status

The GitHub repository has been created and cloned onto the local Mac. The project is ready for its first documented development milestone.
